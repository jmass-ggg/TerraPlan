# TerraPlan frontend

Responsive TerraPlan landing page and land-intelligence workspace built with React, TypeScript, Vinext, Tailwind CSS, and MapLibre.

## Development

```bash
npm install
npm run dev
```

The existing `NEXT_PUBLIC_FARMTWIN_API_URL` environment variable remains unchanged for compatibility. Without it, the workspace intentionally shows a configuration state rather than fabricated environmental readings.
